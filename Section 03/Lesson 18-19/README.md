# 18-19. Challenge — University Structure

> Challenge proposed in lesson 18 and a possible solution presented in lesson 19: create the package structure of a university system.

---

## 📚 Overview

This challenge consists of designing a Java project structure to represent a university, organizing classes into packages by responsibility, following the same package organization approach introduced in lesson 17.

- **admin** — administrative classes (e.g., registration)
- **educational** — academic-related classes (e.g., subject, test)
- **people** — classes representing people in the university (employee, student, teacher)

---

## 🎯 Goal

Practice applying package organization to a new scenario, reinforcing how to split a project into logical, responsibility-based packages.
