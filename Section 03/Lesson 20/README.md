# 20. Comments — Types and Best Practices

> Overview of comment types in Java (Javadoc, single-line, multi-line) and guidance on how and when to use each one.

---

## 📚 Overview

This lesson covers the different types of comments available in Java and best practices for using them effectively in code.

- **Javadoc comments** (`/** ... */`) — used above classes and methods to document their purpose, authorship, and references (e.g., `@author`, `@since`, `@see`, `@param`)
- **Single-line comments** (`// ...`) — used for short, inline explanations of a specific line or statement
- **Multi-line comments** (`/* ... */`) — used for longer explanations spanning multiple lines

---

## 🎯 Goal

Understand the different comment styles in Java and learn when each one is appropriate, keeping code clear and well documented.
