# 17. Project Organization

> How to organize a Java project into packages, grouping classes by responsibility instead of leaving everything in a single flat folder.

---

## 📚 Overview

This lesson shows how to structure a project by splitting classes into packages according to their role in the system. Instead of one flat `src` folder, classes are grouped into subfolders (packages) such as `admin`, `page`, and `people`.

- **admin** — classes related to administrative/scheduling logic
- **page** — entry point (`main`) and page-related classes
- **people** — domain classes representing people (doctor, employee, patient)

---

## 🎯 Goal

Understand why and how to organize a Java project into packages, improving readability and maintainability as the project grows.
